## 6. CLI 底部快捷键与设置页面（已完成，2026-09-28）

- 已将页面动作和通用动作分栏，帮助、返回/取消和退出固定在右侧；搜索、换源搜索和书源检测的取消快捷键保留在左侧且不重复显示 Esc。

## 7. CLI 诊断功能（已完成，2026-09-28）

- 已将 `d` 入口整理为诊断中心，展示书源位置、可用/禁用/不支持/冲突状态和加载诊断。
- 已增加单源快速检查入口，按搜索、书籍信息、目录和正文阶段串行执行，并保留状态、耗时、结果摘要、trace 和诊断。
- 已参考 Android 的单源调试与批量检查边界，将健康摘要与原始请求调试拆成两个页面；诊断页通过 `g` 进入书源调试。
- 已记录失败、空结果、能力缺失、取消和下游阶段未执行等定位信息，不写入书架或阅读业务数据。

## 8. CLI 网络请求与解析调试（已完成，2026-09-28）

已实现调试功能，支持查看书源执行过程中的网络请求结果和返回值，方便分析规则是否正常解析。覆盖：

- 书源搜索。
- 书籍信息。
- 目录。
- 正文原文。

- 处理流程、请求列表、单条响应和解析摘要分别显示；请求列表支持分组索引、单条选择和 `/` 过滤，响应面板只展开当前选中请求。
- 支持查看请求方法、脱敏 URL/请求头/请求体、状态、最终 URL、响应头、重定向、耗时、大小、失败原因和截断提示。
- 支持搜索、书籍信息、目录、正文和书源切换页面按 `v` 查看最近轻量证据，调试页按 `y` 复制当前面板、按 `e` 导出 Markdown 与 JSON。
- 已增加请求观察器、重试/bridge 子请求记录、响应大小上限、总量上限和敏感字段脱敏；多书源并发请求使用全局捕获编号。
- 帮助页已按页面提供顶部 tabs；每个页面按全局导航、页面操作、请求与解析查看分组，诊断和调试快捷键只在帮助页提示。

# 已知差异

本目录登记 [书源规则标准](../standard/README.md) 与 [当前实现](../implementation/README.md) 之间已经核对、稳定复现的差异。只收录长期有效的结构性差异，不写一次性审计过程，不复制能力全文。

## 边界

- 每条差异必须给出标准侧位置、实现侧位置、影响和处理策略。
- 一次性审计、会话过程和未复核猜测写入 `plans.local/`，不进入本目录。
- 能力是否实现的总表见 [能力清单](../standard/capability-inventory.md) 与 [兼容矩阵](../quality/compatibility-matrix.md)；未实现目标的历史设计见 [归档](../archive/README.md)。

条目见 [known-divergences.md](known-divergences.md)。

# 已知差异

历史路径保留说明；现行差异登记已集中到 [兼容性与验证](../compatibility/README.md)。本目录不再新增条目，避免与现行状态形成第二份事实源。

## 边界

- 每条差异必须给出标准侧位置、实现侧位置、影响和处理策略。
- 一次性审计、会话过程和未复核猜测写入 `plans.local/`，不进入本目录。
- 能力是否实现的总表见 [状态总览](../compatibility/status.md)，能力定义和证据见[兼容性与验证](../compatibility/README.md)；未实现目标的历史设计见 [归档](../archive/README.md)。

条目见 [兼容性目录中的 known-divergences.md](../compatibility/known-divergences.md)。

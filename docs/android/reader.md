# 内容阅读

## 初始化和书籍恢复

入口是 `ui/book/read/ReadBookActivity.kt`，初始化数据由 `ReadBookViewModel` 和全局 `model/ReadBook.kt` 协作完成。

`initData` 读取：

- `bookUrl`，没有时回退到最后阅读书。
- `inBookshelf`，决定是否保存阅读进度和书籍变更。
- 目录页返回的章节索引、章节内位置、章节变化标记。
- 高亮返回的标题布局长度和锚文本。

如果是同一本书，调用 `ReadBook.upData` 保留阅读视图和页码状态；换书则 `ReadBook.resetData`。本地文件不存在或没有权限时，发布错误并请求重新选择权限，不继续加载正文。

## 初始化请求顺序

`ReadBookViewModel.initBook` 的网络路径为：

1. 非本地书且 `tocUrl` 为空，先请求详情页。详情失败时显示错误，不继续目录请求。
2. 本地书文件发生变化，或阅读模型没有章节，重新构建本地目录。
3. 网络书调用 `WebBook.getChapterListAwait`，成功后按 URL 变化替换书籍和章节数据库。
4. 目录准备好后，首次进入新书调用 `ReadBook.loadContent(resetPageOffset = true)`，同一本书调用 `loadOrUpContent`。
5. 如果不是显式章节跳转且书在书架中，按配置同步本地或 WebDAV 阅读进度。
6. 非本地书没有书源时，按 `autoChangeSource` 配置尝试自动换源。

加载详情、目录或正文失败时，阅读页使用 `ReadBook.upMsg` 显示阶段错误。正式书架书的成功目录会更新 `bookDao` 和 `bookChapterDao`，临时书可以只保留内存结果。

## 正文和阅读进度

正文通过 `ReadBook`、`ChapterProvider` 和 `WebBook.getContentAwait` 加载。正文结果经过内容处理器、替换规则和书源规则后分页到 `ReadView`。本地 TXT、EPUB、MOBI、漫画、音频和视频由各自的阅读模型处理，不能统一成网络文本。

阅读状态至少包括：

- 当前章节索引和章节 URL。
- 章节内字符位置、页码和页数。
- 当前章节标题、阅读时间和最后阅读时间。
- 当前主题、字号、行距、翻页方式、亮度和滚动模式。
- 朗读位置、自动翻页状态和全文搜索位置。

翻页或章节切换会保存进度，离开阅读页前也会调用 `ReadBook.saveRead`。从目录跳转时先保存原进度，用于返回阅读页时区分“恢复原位置”和“用户主动跳转”。

## 触摸、按键和菜单

阅读正文区域负责显示和隐藏顶部、底部菜单。菜单关闭时，正文区域恢复翻页和选择行为。上一章、下一章在边界处禁用；章节跳转通常需要确认，确认过后可以继续跳转。

顶部菜单进入书籍信息，章节标题和章节 URL 可以交给浏览器或应用内 WebView。底部和溢出菜单包含：

- 目录、章节跳转和进度条。
- 朗读、自动翻页和阅读样式。
- 夜间或日间主题、亮度、字体和更多阅读设置。
- 全文搜索，返回后恢复原阅读位置。
- 书签、高亮、词典、段评、书籍备注和文字选择菜单。
- 书源登录、编辑、禁用、整本书换源、章节换源和批量章节换源。
- 替换规则、目录规则、书籍信息、日志和书源重新导入。

菜单项的可见性由书籍类型、是否存在书源、是否允许更新和当前配置决定。无书源的本地书不显示登录和书源操作。

## 全文搜索和定位

全文搜索由 `SearchContentActivity` 执行。阅读页把查询词、命中列表和当前命中索引放入 `IntentData`。返回时：

1. 恢复搜索结果列表和当前索引。
2. 保存进入全文搜索前的阅读进度。
3. 跳到当前命中的章节和正文位置。
4. 显示搜索结果菜单，不把搜索位置误写成普通阅读进度。

## 书签、高亮和正文编辑

选择文本可以创建书签、高亮、词典查询、段评或复制内容。高亮保存章节 URL、章节索引、正文位置、标题布局长度、原文和备注。章节 URL 变化时，目录页会重新解析章节索引。

正文编辑允许临时查看或保存处理前后的内容。替换规则预览和手动规则弹窗会显示有效规则，但保存正文前仍要经过正常内容处理链路。

## 资源缓存和刷新

正文缓存通过 `BookHelp` 和 `CacheBook` 保存，章节保存成功会发 `EventBus.SAVE_CONTENT`，目录页据此更新缓存标记。图片资源使用独立缓存目录，用户选择目录后保存配置。

书源编辑完成后，阅读页重新加载书源并刷新正文，但保留当前页偏移。资源刷新和书源重新导入有单独的加载状态，不能覆盖普通正文请求的错误。

## 换源和自动换源

整本书换源成功后，阅读模型迁移当前书籍、替换数据库书籍和目录，重置正文并从新书源加载。章节换源只替换指定章节正文，批量换源可能逐章缓存。

自动换源只在当前书没有书源且配置开启时执行。它并发对启用文本书源做精确搜索，依次加载详情、目录和当前章节正文，第一条完整可用结果通过 `take(1)` 提交。全部失败时提示“没有合适书源”，不会自动禁用失败源。

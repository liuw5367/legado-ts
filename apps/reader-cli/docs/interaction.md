# 命令行阅读器交互设计

## 视觉和布局方向

界面采用原生终端的“编辑台”方向：深色终端背景、青色标题、黄色焦点、白色正文和纯文本分隔线。颜色只是辅助，焦点、状态和错误始终通过文字和符号表达。页面不依赖鼠标，建议宽度不小于 48 列；窄终端自动缩短底部键位提示并继续保持可操作。

每个页面由标题栏、上下文栏、主内容区、消息行和键位栏组成。普通信息不使用弹窗，配置、详情、帮助、诊断和书源切换是可返回的完整页面。

## 页面流转

```text
启动/配置
   -> 首页
      -> 搜索编辑 -> 搜索结果 -> 详情 -> 目录 -> 阅读
                                  \-> 已知书源 -> 章节映射/详情
首页 -> 书架/最近阅读恢复 --------------------^
```

详情页和阅读页的 `s` 始终打开本书“已知书源”页。该页面打开时只读取本地 `sources.json`，不会搜索。只有 `m` 才进入扩展搜索，扩展过程在本页逐条显示严格匹配结果，结束后仍停留在本页，用户必须再次选择候选。书架、搜索结果、详情、目录、正文和书源页按 `o` 打开统一操作菜单；`d` 在任意非输入页面打开诊断页。

## 页面行为

### 首页

首页有三个区域：书架、最近阅读、搜索记录。书架项显示书名、作者、当前章节和上次阅读时间；最近阅读项显示 `[书架]` 或 `[未加入]`。未读但已加入书架的书只出现在书架，不会被伪造成阅读记录。搜索记录按规范化名称去重，只保留最新完成的一条，并显示搜索时间和候选数量。

### 搜索结果

提交搜索后立即进入结果页，显示 `已完成/总书源数`、当前正在请求的书源名称、已发现候选数量和累计耗时。书源完成一个就推送一次快照；结果不需要等待全部书源结束即可浏览。结果按完全匹配、包含关键词、其他排序，同书名和作者的候选合并为一项，并显示首次返回书源、聚合书源数量和该候选搜索耗时；`j/k`、方向键和分页键在终端高度内滚动。搜索期间按 `Esc` 会进入“正在取消”状态，等待应用层请求释放后留在结果页并保留已返回结果；只有非搜索状态下的 `Esc` 才返回上一页。

结果聚合键为规范化书名和作者；缺少必要字段时退回 `(sourceId, bookUrl)`。用户打开候选后，应用把本次结果中规范化书名和作者都一致的候选写入该逻辑书的已知书源集合。作者一致标记为 `title-author`，作者缺失或不同的候选不会误并入。

### 详情和目录

详情页显示书名、作者、当前书源、搜索耗时、最新章节、更新时间、简介和书架状态，并提供开始/继续阅读、查看目录、换源、加入书架入口。长简介按终端宽度换行并支持滚动。目录使用单列列表，当前项用 `>`，最近阅读章节在上下文行单独标记。目录加载失败时保留详情，不进入空白阅读页。

### 阅读页

正文按终端列宽换行，只渲染当前视口。章节切换前保留旧正文，目标章节只有在正文成功或带可展示正文的 `partial` 结果后才替换视口。章末翻页不自动切章，避免误触产生网络请求。

阅读位置保存为段落索引和段内字符偏移，窗口缩放后重新排版。打开已有阅读记录时，目录自动定位到上次章节，进入正文后按段落偏移恢复视口；没有对应章节时回退到第一章。保存失败时保留正文并显示错误，不阻断阅读。

### 已知书源

列表状态包括：

- `可用`：sourceId 和 sourceFingerprint 仍匹配当前来源目录。
- `需要重新搜索`：来源定义 fingerprint 已变化。
- `书源已移除`：当前来源目录没有该 sourceId。
- `定义冲突`：同一 sourceId 发现多个不同定义。

`Enter` 只允许使用可用候选。列表行显示来源名称、可用状态、搜索耗时、最新章节和更新时间。`m` 只查询没有有效候选或 fingerprint 已变化的文本书源，已有有效候选跳过请求。扩展搜索同样显示 `已完成/总书源数`、当前书源、已匹配/未匹配数量和累计耗时；严格匹配结果在当前页增量展示，并可用 `j/k` 滚动。结束后只把书名和作者都完整匹配的候选合并到本地列表，不自动替换当前活动书源。

### 统一操作菜单

`o` 在列表项或书籍相关页面打开四项菜单：

1. 继续阅读：加载当前活动书源目录，并定位上次阅读章节。
2. 书籍信息：打开详情页。
3. 章节列表：加载当前活动书源目录。
4. 书源切换：打开本地已知书源列表。

菜单使用 `j/k` 或方向键选择、`Enter` 执行、`Esc` 关闭。当前页面动作、缺少书籍上下文、没有可用书源或异步操作期间会显示禁用原因；页面底部始终保留当前可执行动作提示。

## 错误和取消

异步页面使用 `idle/running/cancelling/complete/cancelled/error` 语义。刷新时保留上一次可用内容，迟到结果不能更新已离开的页面。搜索快照和换源搜索快照都在书源结束后立即刷新；`Esc` 在搜索期间只取消任务，不离开结果/书源页，普通页面则返回上一页。`q` 退出并等待状态写入完成；非 TTY 环境拒绝启动交互界面。

# 命令行阅读器功能说明

## 功能范围

| 功能 | 默认行为 | 持久化或副作用 |
| --- | --- | --- |
| 书源加载 | 从 `--source` 或 `LEGADO_READER_SOURCE` 加载 JSON/JavaScript，目录递归导入并过滤不可用能力 | 远程来源成功响应写入 `~/.config/reader-cli/cache-v1/source-input` |
| 首页 | 分为书架、最近阅读、搜索记录三个区域；所有列表显示绝对序号，支持 `j/k`、方向键逐项移动、`PageUp/PageDown` 或左右键翻页；书架显示作者、当前章节和上海时区的上次阅读时间，搜索历史按规范化名称只显示最新一条并显示完成时间 | 只读 `bookshelf.json`、`reading-history.json`、`search-history.json`、`books/*` |
| 搜索 | 最多四个来源并发；来源完成即推送候选，结果按完全匹配、包含关键词、其他排序，并按书名+作者合并 | 新增一条搜索历史并按名称淘汰旧记录；打开候选后回填 `openedBookIds`，候选保留书源、搜索耗时和返回顺序 |
| 详情 | 对选中候选请求详情，显示作者、简介、当前书源、搜索耗时、最新章节、更新时间和书架状态，并提供阅读/目录/换源入口 | 写入 `books/<bookId>/book.json`，并合并本次搜索中的同书名同作者 `sources.json` |
| 已知书源 | 首次进入只读取本地候选；`m` 才对未记录或规则已变化的来源执行额外搜索；搜索期间逐条显示严格匹配的书源 | 只将书名和作者都完整匹配的候选合并到 `sources.json`，记录搜索耗时、最新章节和更新时间，不自动切换活动版本 |
| 目录 | 使用当前活动书源加载章节，显示序号，打开阅读记录时定位上次章节；支持逐项移动和整页翻页 | 目录结果进入可删除的 `~/.config/reader-cli/cache-v1/toc` |
| 正文 | 先将 HTML 的块级元素转换为段落、标题、引用、列表、预格式文本和图片占位，再按终端宽度换行；按段落锚点恢复位置，左右键/PageUp/PageDown 翻页，支持上一章/下一章 | 正文进入 `~/.config/reader-cli/cache-v1/content`；成功保存后更新 `reading-history.json` |
| 书架 | `a` 添加或移出书架；移出不删除书籍、书源和阅读记录 | 只改写 `bookshelf.json` |
| 取消与退出 | 搜索或换源搜索中的 `Esc` 只取消任务并留在当前结果页；其他页面的 `Esc` 返回上一页；`q`/`Ctrl+C` 先取消再退出 | 应用等待工作流、写队列和缓存索引释放后删除锁 |

## 异步状态约定

每个 UI 异步操作都有一个递增的操作 ID 和 `AbortController`。启动新操作或按 `Esc` 时，旧操作失效；搜索取消会进入 `cancelling` 状态，直到应用层 Promise 结算后才回到 `cancelled`，因此不会遗留“搜索中”。旧 Promise 即使稍后完成，也只能释放自身资源，不能写入已离开的页面。普通搜索和换源搜索都通过快照回调增量刷新候选，应用层继续等待已启动的操作完成，确保网络连接、规则宿主和文件写入不会在退出后悬挂。

用户可见的瞬时状态绑定到产生它的页面；路由切换会清除旧状态，避免上一页的“已加入书架”或“正在加载”误出现在新页面。普通状态统一以黄色显示。时间持久化为 UTC ISO，界面统一转换为 `Asia/Shanghai` 的 `YYYY-MM-DD HH:mm:ss`。

正文 HTML 支持 `p`、`div`、`br`、`h1`–`h6`、`blockquote`、`ul/ol/li`、`pre/code`、`hr` 和图片替代文本；脚本、样式和注释被隐藏。终端不下载图片、不执行 CSS 或 JavaScript。

## 搜索结果规则

- 搜索记录以 NFKC、去首尾空白并合并连续空白后的名称去重，只保留最新完成的一条；首页显示完成时间、候选数量和来源范围摘要。
- 搜索结果使用规范化书名计算等级：书名完全相等为“完全匹配”，查询词出现在书名中为“包含关键词”，其余为“其他”。等级之后按首次返回顺序稳定排序。
- 结果聚合键为规范化书名和作者；缺少书名或作者时退回 `(sourceId, bookUrl)`，避免把不同书误合并。每个聚合项展示首次返回的书源，并保留其他候选供换源。
- 换源搜索沿用同一规则，但只有书名和作者都与当前书籍完整匹配的候选才会出现在增量列表和本地书源记录中。

搜索进度回调是只读通知，字段含义如下：

- `total`：本次实际纳入队列的可用来源数。
- `completed`：已结束的来源数，取消前未开始的来源不会虚报完成。
- `activeSources`：正在请求或执行规则的来源名称。
- `candidates`：已经返回的候选累计数量。
- `success`、`partial`、`empty`、`failed`、`capabilityMissing`、`cancelled`：按来源统计的终态数量。

## 书源切换

如果当前阅读页已有目录，选择目标来源后先加载目标目录，并按规范化章节标题计算映射；找不到同名章节时回退到相同索引并要求用户确认。确认后才更新 `activeEditionKey`。如果当前没有目录，则详情加载成功后直接切换。规则 fingerprint 不匹配、来源被移除或来源冲突时，候选只能重新搜索，不能直接请求。

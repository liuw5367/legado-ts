# 命令行阅读器功能说明

## 功能范围

| 功能 | 默认行为 | 持久化或副作用 |
| --- | --- | --- |
| 书源加载 | 从 `--source` 或 `LEGADO_READER_SOURCE` 加载 JSON/JavaScript，目录递归导入并过滤不可用能力 | 远程来源成功响应写入 `~/.config/reader-cli/cache-v1/source-input` |
| 首页 | 分为书架、最近阅读、搜索记录三个区域；所有列表显示绝对序号，支持 `j/k`、方向键逐项移动、`PageUp/PageDown` 或左右键翻页、Home/End 或 Ctrl+A/Ctrl+E 首尾跳转；按 `s` 进入设置 | 只读 `bookshelf.json`、`reading-history.json`、`search-history.json`、`books/*` |
| 搜索 | 并发数默认 4，可在设置页调整为 1–32；来源完成即推送候选，结果按完全匹配、包含关键词、其他排序，并按书名+作者合并 | 新增一条搜索历史并按名称淘汰旧记录；打开候选后回填 `openedBookIds`，候选保留书源、搜索耗时和返回顺序 |
| 设置 | 配置搜索、换源搜索和书源检测的批量并发数，以及阅读页顶部的书名、章节名、章序、页进度、字数、状态和连接符；并发数默认均为 4，顶部项目默认显示，连接符默认 `·` | 写入 `reader-settings.json`，使用版本化 JSON envelope；旧配置缺失的新字段按默认值补齐 |
| 详情 | 对选中候选请求详情，显示作者、简介、当前书源、搜索耗时、最新章节、更新时间和书架状态，并提供阅读/目录/换源入口 | 写入 `books/<bookId>/book.json`，并合并本次搜索中的同书名同作者 `sources.json` |
| 已知书源 | 首次进入只读取本地候选；当前书源置顶，其余按搜索耗时从短到长排列；`m` 才对未记录或规则已变化的来源执行额外搜索；搜索期间逐条显示严格匹配的书源 | 只将书名和作者都完整匹配的候选合并到 `sources.json`，记录搜索耗时、最新章节和更新时间，不自动切换活动版本 |
| 目录 | 使用指定书源加载目录；支持 `/` 按 NFKC、大小写不敏感的标题筛选，焦点不改变当前阅读章节；再次打开时优先读取当前书活动书源的目录快照，按 `r` 跳过快照重新请求 | 成功目录写入 `data-v1/books/<bookId>/toc/<editionKey 摘要>.json`；其他书源仅临时预览，不新增目录快照 |
| 正文 | 按终端主视口分页，顶部按设置显示书籍信息、章节信息、章序、页进度、字数和简化状态；项目之间使用可配置的 `隐藏`、`·` 或 `—` 连接，隐藏连接符时相邻项目只保留一个空格；上下箭头翻页、左右箭头切换章节，`r` 刷新 | 正文写入 `data-v1/books/<bookId>/content/<content identity 摘要>.json`；打开章节后立即保存阅读章节与来源，翻页后节流保存段落位置 |
| 书架 | `a` 添加或移出书架；移出不删除书籍、书源和阅读记录 | 只改写 `bookshelf.json` |
| 返回与取消 | `⎋` 按实际导航栈返回；内容页按进入顺序保留实例，工具页使用单例栈并在再次打开时清除其上方页面；章节映射确认后替换为目录或详情；搜索或换源搜索中的第一次 `⎋` 先取消并留在当前页，普通任务取消后也保留页面；`q`/`Ctrl+C` 先取消再退出 | 应用等待工作流、写队列和缓存索引释放后删除锁 |
| 诊断中心 | `d` 打开书源状态和加载诊断；诊断页在当前导航任务中保持单例，可按来源进入快速调试 | 只保留当前进程内的诊断和调试证据，不写入书籍、书架或普通缓存 |
| 请求与解析调试 | `g` 从诊断中心进入单源搜索、详情、目录、正文调试；同一书源只保留一个调试页实例；`v` 从搜索、详情、书源、目录和阅读页面查看最近操作 | 请求正文、响应头和处理流程只保留在内存；`y` 复制当前面板，`e` 导出脱敏 Markdown 与 JSON |

## 异步状态约定

每个 UI 异步操作都有一个递增的操作 ID 和 `AbortController`。启动新操作或按 `⎋` 时，旧操作失效；搜索取消会进入 `cancelling` 状态，直到应用层 Promise 结算后才回到 `cancelled`，因此不会遗留“搜索中”。旧 Promise 即使稍后完成，也只能释放自身资源，不能写入已离开的页面。普通搜索和换源搜索都通过快照回调增量刷新候选，应用层继续等待已启动的操作完成，确保网络连接、规则宿主和文件写入不会在退出后悬挂。

用户可见的瞬时状态绑定到产生它的页面；路由切换会清除旧状态，避免上一页的“已加入书架”或“正在加载”误出现在新页面。普通状态统一以黄色显示。时间持久化为 UTC ISO，界面统一转换为 `Asia/Shanghai` 的 `YYYY-MM-DD HH:mm:ss`。

正文 HTML 支持 `p`、`div`、`br`、`h1`–`h6`、`blockquote`、`ul/ol/li`、`pre/code`、`hr` 和图片替代文本；脚本、样式和注释被隐藏。终端不下载图片、不执行 CSS 或 JavaScript。

## 诊断与调试

诊断中心按书源显示可用、禁用、不支持、冲突和无效加载状态。禁用或不可用的来源只能查看原因，不能发起网络检查。对可用来源按 `g` 进入单源调试，按 `r` 执行搜索、书籍信息、目录、正文的快速检查；默认使用书源 `checkKeyWord`，没有配置时使用“我的”；按 `i` 可修改关键词。调试按搜索、书籍信息、目录、正文顺序推进，每个阶段保留状态、诊断、候选/章节/正文摘要和 source-core trace。

调试页把请求分成“阶段 → 书源 → 请求序号”的摘要索引，详情面板只显示当前选中的请求。`/` 在请求列表中按书源、阶段、路径、状态和错误摘要过滤；在原始响应面板中按已捕获正文行过滤。`l` 显示请求、响应解码、规则、字段、候选和结果的处理流程，`n` 显示请求列表，`r` 显示当前响应，`p` 显示解析摘要。普通页面按 `v` 只能查看最近一次轻量证据；命中缓存且没有新请求时会明确显示没有网络记录。

请求观察器在 source-core 的真实 `RequestPlan` 与 `NetworkHost` 之间记录每次尝试、重试、状态码、最终 URL、响应头和有上限的响应前缀。展示和导出前会脱敏认证头、Cookie、token、密码、签名参数等敏感值。轻量证据最多保留 32 条请求、单响应 128 KiB、总响应 512 KiB；完整调试最多保留 100 条请求、单响应 512 KiB、总响应 4 MiB。`y` 复制当前面板；`e` 在 `~/.legado-reader/exports/` 生成 Markdown 和 JSON，剪贴板命令不可用时不影响文件导出。

帮助页通过顶部 tabs 查看所有页面，按全局导航、当前页面、列表筛选和请求解析查看分组，支持 Tab/Shift+Tab 或左右键切换、Ctrl+A/E 首尾跳转；诊断、调试、查看请求、复制和导出键位只在帮助页显示，不占用页面底部命令栏。通用帮助、返回/取消和退出提示在底部右侧，搜索或检测取消提示在左侧。

## 搜索结果规则

- 搜索记录以 NFKC、去首尾空白并合并连续空白后的名称去重，只保留最新完成的一条；首页显示完成时间、候选数量和来源范围摘要。
- 搜索结果使用规范化书名计算等级：书名完全相等为“完全匹配”，查询词出现在书名中为“包含关键词”，其余为“其他”。等级之后按首次返回顺序稳定排序。
- 结果聚合键为规范化书名和作者；缺少书名或作者时退回 `(sourceId, bookUrl)`，避免把不同书误合并。每个聚合项展示首次返回的书源，并保留其他候选供换源。
- 换源搜索沿用同一规则，但只有书名和作者都与当前书籍完整匹配的候选才会出现在增量列表和本地书源记录中。

搜索进度回调是只读通知，字段含义如下：

- `total`：本次实际纳入队列的可用来源数。
- `completed`：已结束的来源数，取消前未开始的来源不会虚报完成。
- `activeSources`：正在请求或执行规则的来源名称。
- `candidates`：已经返回的候选累计数量。
- `success`、`partial`、`empty`、`failed`、`capabilityMissing`、`cancelled`：按来源统计的终态数量。

## 书源切换

书源列表按 `t` 只读预览选中来源目录；`↵` 保留原有活动来源切换和章节映射行为。预览目录中直接选择章节阅读时，先加载正文并写入目标来源的阅读记录，再同步书籍元数据。若同步失败，阅读记录为恢复依据，下次打开会补齐书籍活动来源。规则 fingerprint 不匹配、来源被移除或来源冲突时，候选不能直接打开目录。

在书籍信息页打开书源列表后直接切换成功，会返回原书籍信息条目并刷新来源信息，不额外创建重复的详情历史记录。

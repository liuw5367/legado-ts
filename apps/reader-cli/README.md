# @legado/reader-cli

`@legado/reader-cli` 是基于 `@legado/source-core` 和 `@legado/source-node` 的交互式命令行阅读器。它负责来源加载、搜索、书籍信息、目录、正文、书架和本地阅读状态，核心 package 只负责书源规则解释和阅读工作流。

## 使用

先构建 workspace：

```bash
pnpm build
```

通过参数或环境变量提供书源：

```bash
node apps/reader-cli/dist/index.js --source ./fixtures/source
LEGADO_READER_SOURCE=https://example.test/sources.json node apps/reader-cli/dist/index.js
```

参数 `--source` 优先于 `LEGADO_READER_SOURCE`。来源可以是单个 JSON/JavaScript 文件、目录或 HTTP/HTTPS JSON 地址。目录递归读取 `.json` 和 `.js`，不跟随符号链接；导入和网络响应均有字节、文件数和候选数限制。

## 功能边界

- 首页包含书架、最近阅读和搜索记录入口。
- 搜索并发最多四个书源；某个书源返回后立即把候选增量显示在结果页，并将同书名、同作者的候选合并为一项。
- 结果按完全匹配、包含关键词、其他三档排序；列表显示绝对序号，支持 j/k 或上下键逐项移动、左右键或 PageUp/PageDown 翻页、Home/End 首尾跳转。
- 搜索页实时显示 `已完成/总书源数`、当前书源和候选数量；搜索中按 `Esc` 取消但留在结果页，保留已返回结果，只有非搜索状态下的 `Esc` 才返回上一页。
- 页面共用一行上下文栏、弹性正文区和固定命令栏；40×12 以下显示尺寸提示。较高终端会用分隔线区分正文与命令栏。
- 目录可按 `/` 输入章节标题筛选，支持 NFKC 和大小写不敏感匹配；按 `r` 绕过目录响应缓存重新请求，按 `s` 切换正序或倒序；焦点选择与当前阅读章节分离。
- 书架或最近阅读按 `Enter` 直接打开上次阅读章节；阅读页显示当前可视页/总页数和章节非空白字数，上下箭头或 `j/k` 翻页，左右箭头或 `h/l` 切换章节，`i` 打开书籍信息，`r` 刷新当前正文。
- 详情页提供阅读、目录、书源和书架操作，不再提供重复的 `o` 快捷键。界面时间统一为上海时区 `YYYY-MM-DD HH:mm:ss`。
- `o` 只在书架/最近阅读与搜索结果打开统一操作菜单；菜单覆盖显示，关闭后恢复底层位置。
- 已知书源页只读本地候选，当前书源只显示“当前”；本地书源和扩展搜索结果的最新章节最多显示 20 个完整字符簇；`t` 预览选中书源目录，`Enter` 保留现有切换/章节映射行为。直接阅读非当前书源的章节时，正文成功后会更新活动书源和阅读记录。
- 从书籍信息页打开书源列表并直接切换成功后，关闭书源页、回到原书籍信息页并更新信息，不另压入重复详情历史。
- `Esc` 按实际进入顺序返回；搜索或普通任务进行中第一次 `Esc` 先取消任务，不离开当前页。
- 首版仅处理文本书源，音频、图片、视频、文件下载、登录和 WebView 需要后续宿主能力。

## 常用按键

| 页面 | 按键 |
| --- | --- |
| 全局 | `Ctrl+K` 搜书，`?` 当前页帮助，`d` 诊断，`Esc` 取消当前任务或按进入顺序返回，`q` 退出 |
| 搜索 | 输入关键词，`Enter` 提交 |
| 列表 | `j/k`、上下方向键移动，左右方向键或 `PageUp/PageDown` 翻页，`Home/End` 首尾，`Enter` 打开；书架/搜索结果可用 `o` 操作 |
| 详情 | `Enter` 直接阅读，`t` 目录，`s` 书源，`a` 书架 |
| 目录 | `j/k`、上下方向键移动，`/` 搜索章节，`r` 重新请求目录，`s` 切换正序/倒序，`Esc` 清除筛选或返回，`Home/End` 首尾，`Enter` 阅读 |
| 阅读 | 上下方向键或 `j/k` 翻页，左右方向键或 `h/l` 切换章节，`PageUp/PageDown` 或空格也可翻页，`i` 书籍信息，`t` 目录，`s` 书源，`a` 书架，`r` 刷新正文 |
| 已知书源 | `t` 预览目录，`Enter` 切换或进入章节映射，`m` 搜索更多 |

`o` 菜单固定提供“阅读、书籍信息、章节列表、书源切换”。当前页面或普通异步操作不允许的动作会显示禁用原因；搜索中已返回的候选仍可操作，执行时会先取消剩余来源；底部键位栏始终只显示一行，放不下的低优先级动作会省略。HTML 输入不会执行脚本或下载图片。

## 验证

```bash
pnpm --filter @legado/reader-cli build
pnpm --filter @legado/reader-cli test
```

非 TTY 环境只支持 `--help` 和 `--version`，不会启动备用屏幕或写入阅读状态。

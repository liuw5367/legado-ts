# reader-web 交互说明

## 路由

| 路由 | 页面 | 主要操作 |
| --- | --- | --- |
| `/login`、`/register` | 登录、注册 | 邮箱密码登录、注册和邮箱验证提示 |
| `/forgot-password`、`/reset-password` | 找回和重置密码 | 发送恢复邮件、设置新密码 |
| `/` | 账户首页 | 最近阅读、书架、搜索历史和移出书架 |
| `/search` | 搜索 | 关键词、精准搜索、流式候选、取消、创建或追加书籍 |
| `/sources` | 书源管理 | 分页筛选、导入预览、确认、启用、禁用和删除 |
| `/books/:bookId/sources` | 书籍来源 | 查看同书不同来源、再次搜索和选择来源 |
| `/books/:bookId/toc` | 目录 | 切换 edition、阅读章节、刷新目录 |
| `/books/:bookId/read/:chapterId` | 阅读 | 上一章、目录、下一章、换源和保存阅读位置 |
| `/account/settings` | 阅读设置 | 系统/浅色/夜间模式、字号和行距 |

未登录访问受保护路由时回到 `/login`，登录后恢复原目标路径。认证回调使用 `/auth/confirm`，恢复密码使用 `/reset-password`。

## 搜索

搜索页只提交关键词和精准选项，来源范围由服务端读取当前账号已启用书源。候选到达时列表即时更新，并显示来源状态和进度。用户可以在搜索完成前打开已有候选；取消后已返回候选仍可创建书籍。下一页只对仍有游标的来源发起请求，并复用原搜索记录。

创建书籍时，用户可以选择加入书架或仅保存书籍；已有书籍可以接收新的来源版本。打开目录前，页面会把候选详情加载成 edition，失败时保留搜索结果并显示错误。

## 书源管理与来源切换

导入先显示候选、版本比较结果和不会写入的原因。预览过期或服务端无法安全判断版本时，页面要求重新预览，不直接覆盖现有源。批量动作完成后刷新分页列表。

书籍来源页面只展示当前用户可用的 source editions。查看其他来源目录不会改变阅读来源；点击该来源的章节后才切换 edition，并使用新来源的目录、正文和阅读位置。当前来源在列表中单独标记。

## 目录与阅读

目录页按 edition 显示章节列表，支持手动刷新。正文页使用独立阅读栏和底部上一章/目录/下一章控制，阅读设置从账号设置读取。页面加载时同时读取目录、正文和位置；保存位置带 paragraphIndex、offset、tocRevision 和 version，服务端按用户、书籍和 edition 更新。

空目录、空正文、来源能力缺失、网络失败和取消分别显示可识别状态。正文加载失败不会删除已有缓存或阅读位置。

## 视觉约束

颜色、字号、行距、响应式断点和控件尺寸以 [`DESIGN.md`](../DESIGN.md) 为准。页面实现不得在本文件复制视觉 token；交互文档只记录用户可观察的页面结构和状态。

# reader-web 交互说明

## 路由

| 路由 | 页面 | 主要操作 |
| --- | --- | --- |
| `/login`、`/register` | 登录、注册 | 邮箱密码登录、注册和邮箱验证提示 |
| `/forgot-password`、`/reset-password` | 找回和重置密码 | 发送恢复邮件、设置新密码 |
| `/account/password` | 修改密码 | 验证当前密码并设置新密码 |
| `/` | 账户首页 | 最近阅读、书架、搜索历史和移出书架 |
| `/search` | 搜索 | 关键词、精准搜索、流式候选、取消、创建或追加书籍 |
| `/sources` | 书源管理 | 全量筛选、导入预览、确认、启用、禁用和删除 |
| `/books/:bookId/details` | 书籍详情 | 当前来源的简介、最新章节、阅读、目录、书架和换源入口 |
| `/books/:bookId/sources` | 书籍来源 | 查看同书不同来源、再次搜索和选择来源 |
| `/books/:bookId/toc` | 目录 | 切换 edition、阅读章节、刷新目录 |
| `/books/:bookId/read/:chapterId` | 阅读 | 上一章、目录、下一章、换源和保存阅读位置 |
| `/account/settings` | 账号设置 | 修改密码、书源管理、阅读设置和退出登录 |
| `/account/settings/reading` | 阅读设置 | 系统/浅色/夜间模式、滚动/分页阅读、字号、行距和正文四边距 |

未登录访问受保护路由时回到 `/login`，登录后恢复原目标路径。认证回调使用 `/auth/confirm`，恢复密码使用 `/reset-password`。修改密码、忘记密码和设置新密码页面在标题左侧提供统一的返回按钮，不在页面底部重复显示返回入口。

## 搜索

搜索页只提交关键词和精准选项，来源范围由服务端读取当前账号已启用书源。精确选项位于搜索按钮左侧；搜索中同一按钮变为取消。页面会自动继续请求仍有下一页的来源，显示本次搜索的全部候选；搜索中按约 5 秒更新一次已完成/总书源进度，完成时立即显示最终进度。用户可以在搜索完成前打开已有候选；取消后已返回候选仍可创建书籍。点击封面、书名或简介打开详情，添加书架、目录和来源选择各自独立。

加入书架后，同一搜索中书名与已知作者完全匹配的其他来源会持久缓存；后续搜索完成或取消时也会补充书架书籍的已返回来源。缺失作者不自动合并。缓存失败单独提示，不撤销已保存书籍或搜索结果。

创建书籍时，用户可以选择加入书架或仅保存书籍；已有书籍可以接收新的来源版本。打开目录前，页面会把候选详情加载成 edition，失败时保留搜索结果并显示错误。

## 书源管理与来源切换

导入支持最多五次 HTTP 重定向，每次跳转仍执行目标安全检查；不处理网页脚本跳转。导入先显示候选、版本比较结果和不会写入的原因。预览过期或服务端无法安全判断版本时，页面要求重新预览，不直接覆盖现有源。管理页顶部左侧提供统一返回按钮，右侧导入按钮使用与书架操作按钮相同的紧凑尺寸；页面显示当前筛选的全部书源，批量动作按最多 1000 项分批提交，完成后刷新列表。

书籍来源页面合并已保存的 edition 和书架书籍的来源候选缓存，分别标记“已保存”“已发现”和“当前使用”，并在当前页搜索更多来源。每项提供查看目录和切换书源；长 URL 在文本列内省略，不挤压按钮。点击已发现来源才加载详情，失败留在当前页可重试。已发现表示曾经搜索成功，不保证站点此刻在线。查看其他来源目录不会改变阅读来源；切换按钮按该 edition 的阅读位置或首个可读章节进入正文。目录与换源页左上角使用“返回”，回到进入该页的站内页面；直接打开时分别回到书架和本书目录。

## 目录与阅读

目录页按 edition 显示章节列表，标题、返回、来源选择、操作按钮和筛选固定在顶部，长目录滚动时仍可操作。切换 edition 保留原返回目标，支持手动刷新。

正文页顶部和底部操作栏默认隐藏；点击正文显示，再次点击隐藏，滚动或选字不触发切换。正文聚焦后 Enter 切换，Escape 优先关闭抽屉或分页区域说明，否则隐藏操作栏。滚动模式下底部第一行显示上一章、章节字数、下一章；分页模式下显示当前页/总页数和章节字数，页面左侧翻上一页、右侧翻下一页、中间切换操作栏显隐，页面本身不提供手动滚动。分页模式的翻页区域说明位于顶部更多菜单中，打开遮罩显示左侧、中央和右侧的点击作用，点击遮罩任意位置即可关闭。第二行提供目录、换源、设置和日夜模式图标。分页正文铺满阅读视口，不为隐藏的顶部和底部操作栏预留空间，只保留安全区域和阅读设置中的上下左右正文边距。目录抽屉的操作区左侧显示“完整目录”入口，右侧提供倒序、到顶部、到底部和刷新目录数据；这些操作在同一行左右分布。刷新成功后更新当前书籍的共享目录缓存，失败时保留现有目录并显示重试入口。完整目录页的选中章节使用与目录抽屉一致的较大对号。字数按展示正文的 Unicode 字符计数，排除空白、包含标点，不含标题。日夜快捷键以当前实际模式切换并保存账号偏好，保存失败可重试；设置仍可选择跟随系统。阅读设置从账号设置读取，支持设置正文上、右、下、左四边距。操作栏显隐保持正文布局与滚动位置。页面加载时同时读取目录、正文和位置；当前章节正文只保留一条内存缓存，重新进入同一章时先显示缓存，再请求最新内容并覆盖缓存；切换章节、书籍或书源后旧正文缓存不再使用。保存位置带 paragraphIndex、offset、tocRevision 和 version，服务端按用户、书籍和 edition 更新。

空目录、空正文、来源能力缺失、网络失败和取消分别显示可识别状态。正文加载失败不会删除已有缓存或阅读位置。

书架和阅读记录直接打开正文；翻章、目录抽屉和换源保留原返回目标，返回时恢复首页对应标签。阅读顶部仅显示章节标题本身，不额外添加数字序号，右侧使用与书架条目一致的更多菜单，提供书籍详情、查看原文、刷新内容；分页模式额外提供翻页区域说明。点击其他区域或按 Escape 会自动关闭菜单；刷新失败保留当前正文，成功后尽量恢复可见段落。

底部导航、阅读栏和抽屉避让安全区域，顶部增加间距，标题区优先横排。抽屉点击外侧区域、关闭按钮或按 Escape 关闭。账号设置顶部显示账号，下方依次提供修改密码、书源管理和阅读设置入口，阅读设置进入二级页面，底部的退出登录按钮使用淡红色强调；字号、行距和正文四边距均保留滑块，并提供减小、增大按钮，字号步长为 1，行距步长为 0.1，边距范围为 0～64px，保存成功不显示额外提示，失败仍显示错误。

## 视觉约束

颜色、字号、行距、响应式断点和控件尺寸以 [`DESIGN.md`](../DESIGN.md) 为准。页面实现不得在本文件复制视觉 token；交互文档只记录用户可观察的页面结构和状态。

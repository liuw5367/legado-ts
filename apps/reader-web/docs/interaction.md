# reader-web 交互说明

## 路由

| 路由 | 页面 | 主要操作 |
| --- | --- | --- |
| `/login`、`/register` | 登录、注册 | 邮箱密码登录、注册和邮箱验证提示 |
| `/forgot-password`、`/reset-password` | 找回和重置密码 | 发送恢复邮件、设置新密码 |
| `/account/password` | 修改密码 | 验证当前密码并设置新密码 |
| `/` | 账户首页 | 最近阅读、书架、搜索历史和移出书架 |
| `/book-lists`、`/book-lists/:listId` | 书单与详情 | 管理书单、独立评价、搜索添加与移除恢复 |
| `/account/settings/bookshelf-groups` | 书架分组 | 名称、顺序、删除与启动显示分组 |
| `/discover` | 发现 | 当前书源的分类 Tab、分页书籍列表、切换书源和搜索入口 |
| `/search` | 搜索 | 关键词、精准搜索、流式候选、取消、创建或追加书籍 |
| `/sources/import-history`、`/sources/import-history/:batchId` | 导入记录与明细 | 分页查看来源、时间、导入项及撤销 |
| `/sources/import-links` | 来源排序 | 置顶、上移和下移导入链接 |
| `/sources` | 书源管理 | 全量筛选、导入预览、确认、启用、禁用和删除 |
| `/books/:bookId/details` | 书籍详情 | 当前来源的简介、最新章节、阅读、目录、书架和换源入口 |
| `/books/:bookId/sources` | 书籍来源 | 查看同书不同来源、再次搜索和选择来源 |
| `/books/:bookId/toc` | 目录 | 切换 edition、阅读章节、刷新目录 |
| `/books/:bookId/read/:chapterId` | 阅读 | 上一章、目录、下一章、换源和保存阅读位置 |
| `/account/settings` | 账号设置 | 修改密码、书源管理、阅读设置和退出登录 |
| `/account/settings/notes` | 笔记 | 搜索摘录与想法、筛选书籍、删除和恢复 |
| `/account/settings/reading` | 阅读设置 | 系统/浅色/夜间模式、滚动/分页阅读、字号、行距和正文四边距 |

未登录访问受保护路由时回到 `/login`，登录后恢复原目标路径。认证回调使用 `/auth/confirm`，恢复密码使用 `/reset-password`。修改密码、忘记密码和设置新密码页面在标题左侧提供统一的返回按钮，不在页面底部重复显示返回入口。

HTML 首先显示页灯图标和“正在点亮页灯…”，随后异步加载应用、样式和当前路由页面。页面代码加载期间保留账户导航，显示“正在加载页面…”；认证校验显示“正在读取登录状态…”。应用或页面资源下载失败时停止加载动画，提供主动刷新操作；页面资源失败时仍可通过已有导航或返回入口离开。

页面首次请求使用统一的居中图标和下方说明，已有返回语义的页面在说明下方显示无箭头的次要按钮“返回页面”，不重复显示顶部返回按钮；路由代码加载期间采用相同返回样式。详情、来源及书源管理保留标题，首页保留标题和标签。数据成功或失败后恢复原页面导航位置；失败显示错误及恢复操作。嵌入页面的成功和失败提示提供关闭按钮，关闭仅收起提示，不撤销操作；后续操作仍可重新显示结果。已有结果、目录、正文及列表刷新时保留内容，使用紧凑状态或操作按钮提示；搜索尚无结果时居中显示进度，结果到达后在列表上方显示紧凑进度。设置继续先展示本地值，表单提交保留按钮内的等待提示。

## 页面保留与返回

站内按钮式导航入口保留链接语义，在 iOS 上关闭长按链接预览；外部链接和正文保持系统长按行为。

书架、书单、设置各复用一个根页面，发现作为内容页；搜索、详情、目录、来源及其他内容页面最多保留八个实例，正文另保留一个实例。页面按访问需要创建，超限时淘汰最久未激活的隐藏内容页；返回已淘汰页面时重新加载。密码及认证页面离开后销毁。刷新浏览器重新加载当前 URL，退出或切换账号清除旧账号页面。

保留页面恢复输入、筛选、展开状态、滚动位置和焦点；已有成功数据且未失效时不重新请求，已有错误保留重试入口。业务写入成功后刷新相关数据，刷新失败保留内容和错误。临时菜单、抽屉及未保存的翻页区域草稿在离开时关闭。隐藏页面不监听全局滚动、不执行窗口定位或分页测量。

应用返回与浏览器后退使用同一条历史；直接打开链接或历史来源未知时，应用返回使用安全的站内兜底地址。主导航进入对应根页面并恢复其最新状态，重复点击当前根页不新增历史。普通内容进入创建历史条目，上一章、下一章及阅读抽屉选章替换当前条目。从阅读打开完整目录、详情或来源后继续阅读，在来源条目仍可确认时返回原阅读条目并替换目标章节，避免中间页面形成返回循环。

搜索隐藏时取消尚未完成的搜索并保留已有候选，恢复不自动重新搜索。页面读取取消后不会一直显示加载；已提交的业务写入继续结算，成功后即使原页面隐藏也会通知相关页面刷新。书源批量管理离开后不再提交下一批，已发送批次完成后保留实际结果。

## 发现与搜索入口

主导航为书架、书单和设置；启动首页仍是书架，发现入口位于书单首页右上角。发现页一次展示一个书源，标题下方使用横向滚动的分类 Tab，书籍以紧凑单列展示。顶部浅色搜索按钮打开独立搜索页，右上角切换按钮打开书源选择抽屉，支持名称和分组筛选。切换发现书源不会改变账号默认搜索书源。

首次进入按管理顺序选择首个可用书源和首个有效分类；之后按账号在当前浏览器记住最近选择，URL 中的 sourceId、categoryId 优先。被删除、停用的书源或失效分类回到首个可用项。退出账号清除发现偏好及列表状态。无可用书源时显示书源管理入口，加载失败提供重试和切换操作。

发现只查询当前分类的一页，底部“加载更多”按书源游标追加下一页；没有下一页、游标重复或后续页没有新增书籍时结束。翻页失败保留已有列表，重试同一页；详情失败重试原书，不触发翻页。切换书源或分类后旧书籍不可操作，请求失败保留重试和切源入口。点击书籍进入详情，打开详情本身不加入书架、不切换已有书籍的活动来源，也不覆盖书架展示信息。返回发现恢复当前分类、已加载列表和滚动位置；刷新页面重新查询当前分类第一页。

发现支持静态 JSON、title::url 文本分类及 JS 书源的静态分类和 explore 函数。动态 JS 生成分类、exploreScreen 自定义筛选暂不支持，动态分类会显示明确说明。分类来自账号可用书源；分页游标绑定账号、书源版本和分类，使用既有 SOURCE_RUNTIME_STATE_KEY 签名，不需要新增配置。打开详情时重新验证原页候选，列表变化导致候选消失时提示刷新。

## 搜索

搜索页默认使用当前账号每个域名的默认实现。结果候选按域名分组；同一域名有多个实现时，可选择本次候选，也可切换该域名的账号默认实现。切换会等待当前搜索结束；已有关键词时按新默认版本重新搜索，没有关键词时后续搜索会使用新默认版本。此选择影响账号后续搜索，不会改变书籍当前 edition。版本选项显示书源 JSON 的规则更新时间。精确选项使用与搜索输入同高的二态选择按钮，位于搜索按钮左侧；搜索中选择按钮禁用，同一主按钮变为取消。页面会自动继续请求仍有下一页的来源，保留本次搜索的全部候选，首屏展示 50 本并可继续显示；搜索中按约 5 秒更新一次已完成/总书源进度，完成时立即显示最终进度。用户可以在搜索完成前打开已有候选；取消后已返回候选仍可创建书籍。点击封面、书名或简介打开详情，加入书架、加入书单、目录和来源选择各自独立。

首页从其他页面返回时，标题、搜索入口和书架、阅读、搜索三个标签在数据请求期间保持显示，加载提示只位于当前内容区。请求完成后再显示数量；请求失败显示可重试状态，不把失败当作空数据。

加入书架后，同一搜索中书名与已知作者完全匹配的其他来源会持久缓存；后续搜索完成或取消时也会补充书架书籍的已返回来源。缺失作者不自动合并。缓存失败单独提示，不撤销已保存书籍或搜索结果。

创建书籍时，用户可以选择加入书架或仅保存书籍；已有书籍可以接收新的来源版本。打开目录前，页面会把候选详情加载成 edition，失败时保留搜索结果并显示错误。

## 书单与书架分组

书单首页按内容更新时间倒序展示，左侧为前四本书的四分封面，整体尺寸沿用书籍封面；缺格和无封面的格子使用书籍图标占位。右侧为名称、两行描述、数量和更新时间，更多菜单提供编辑和删除。右上角为带图标的发现和新增。书单名称必填，允许重名；描述可空。公开字段保留为 false，不提供公开访问。

书单详情标题栏显示返回入口和书单名称，下方依次显示完整描述和信息行，信息行按更新时间、创建时间、有效书籍数量排列。信息下面固定为编辑信息、添加书籍两个等宽大按钮。添加书籍进入搜索，不允许手工录入书籍。书籍项显示封面、名称、作者及下方独立评价，编辑和移除按钮在封面行右侧垂直排列；点击主信息进入书籍详情；评价只属于当前书单，来源和阅读位置跟随真实书籍数据。修改书单、成员和评价更新时间，阅读与换源不改变书单排序。

搜索结果、书籍详情和书架菜单共用单选书单选择窗口；搜索结果按钮为加入书架、加入书单、目录。加入书单始终弹窗，从书单进入搜索仅预选来源书单，确认前不写入。窗口直接展示全部书单，支持查看已加入状态和新建，不提供搜索框；新建使用同一窗口子视图。列表项使用紧凑分割线；底栏新建靠左，取消和确认靠右。书架的移入书单操作在加入成功后移出书架，整体失败时保留原状态，不删除书籍和阅读记录。

书单移除立即保存，但当前历史条目的行仍保留，显示已移除与加入按钮；恢复保留评价和原加入时间。进入其他页面再返回时合并新增成员与最新信息，并保留移除行。书单详情另有账号范围的轻量历史快照，内容实例淘汰后仍可恢复；随最多一百条历史映射、分支丢弃和账号退出清理。滚动恢复使用可见书籍锚点，刷新浏览器后按实际成员重新加载。书单已删除时显示不可用和返回入口，不保留旧操作。

书架保留书架、阅读、搜索三个 Tab。仅书架 Tab 在有自定义分组时显示单选分组栏，顺序为全部、默认、自定义顺序；没有自定义组则隐藏。全部显示整个书架，默认表示未分组，每本书最多属于一个组。分组栏窄屏横向滚动，组内沿用书架排序。书籍详情的修改分组与书架菜单复用分组选择窗口；未在书架的书先加入默认组，重复加入保留原分组。修改归属后立即退出不匹配的筛选列表。

设置的书架分组页支持新建、名称编辑、上移下移与删除，组名与右侧操作按钮同排且垂直居中；自定义名称为 1–30 字，同账号唯一，不能使用全部和默认。默认没有管理操作。删除时默认把组内书籍归入默认；勾选同时将组内书籍移出书架时移除书架关系，两种方式均保留书籍、阅读记录和普通书单。当前查看组被删后回到全部。

启动时显示的分组标签与右侧选择器同排。选项包括全部、默认和自定义组，保存后下次打开或刷新生效。站内返回已有书架恢复当前查看组，不反复应用启动设置。删除启动目标自动改为全部，旧设置与失效目标也使用全部。

## 书源管理与来源切换

导入支持最多五次 HTTP 重定向，每次跳转仍执行目标安全检查；不处理网页脚本跳转。导入先显示候选、版本比较结果和不会写入的原因。预览过期或服务端无法安全判断版本时，页面要求重新预览，不直接覆盖现有源。管理页暂不展示条目的登录入口。管理页按来源域名分组；正常状态下每个域名只有一个账号默认实现，旧数据存在多个启用项时会显示警告，并按管理顺序确定运行时有效实现。同名实现显示编号。规则更新时间取导入 JSON 的 `lastUpdateTime`，用于识别规则版本新旧，不是 reader-web 内的编辑时间。管理页顶部左侧提供统一返回按钮，右侧导入按钮使用与书架操作按钮相同的紧凑尺寸；页面筛选覆盖全部书源并直接展示全部匹配域名，搜索与状态筛选保留已选项，批量动作按最多 1000 项分批提交，完成后刷新列表。

管理页提供导入记录和来源排序入口，每条书源可反查历史；新导入项展示导入时间，旧数据明确显示未记录。历史按时间倒序，每次加载 20 条，底部加载更多追加记录；整条记录可点击，右侧保留查看明细按钮。明细不分页，默认展示该批次全部实际导入项，也可查看跳过和未选择项。名称、分组和来源使用当时摘要，后来改名、删除或原链接失效不影响查看。URL 参数值始终隐藏。

明细支持选中撤销或整批撤销。确认 Sheet 显示将移除的新增源、将恢复的旧配置及不能撤销的原因，只提交可执行项。版本变化使提交失败时重新加载撤销预览；网络结果未知时重试沿用幂等键。撤销后保留明细并标记部分或全部撤销，不删除书架和阅读进度。备份恢复界面说明导入历史不随备份迁移，旧历史恢复后不可撤销。

来源排序页面显示链接、当前归属书源数及历史入口。新链接追加末尾，重复导入沿用原顺序；其他书源固定最后。搜索与换源按高优先组依次执行，进度显示当前来源组。调整排序只影响新搜索；服务器繁忙或断线时保留已有结果并提供继续按钮，停止操作取消整次搜索。

书籍来源页面合并已保存的 edition 和书架书籍的来源候选缓存，按域名分组，分别标记“已保存”“已发现”和“当前使用”。同域的其他实现也会列出，包括停用或尚未搜索过本书的版本；可设为账号默认，未搜索过的版本可只针对本书发起搜索。选择其他实现会更新账号默认书源。查看目录不会更改本书当前 edition；切换按钮按目标 edition 的阅读位置或首个可读章节进入正文。长 URL 在文本列内省略，不挤压按钮。点击已发现来源才加载详情，失败留在当前页可重试。已发现表示曾经搜索成功，不保证站点此刻在线。目录与换源页左上角使用“返回”，回到进入该页的站内页面；直接打开时分别回到书架和本书目录。

## 切换封面

书籍详情的封面可点击，打开切换封面 Sheet。先显示当前封面，再显示这本书已经搜索到且仍有效的来源；已有封面立即展示，缺少封面的已发现来源按管理顺序逐个读取详情。每项显示书源名称、域名和等待、读取中、无封面或失败状态，相同图片 URL 合并并可展开来源名称。图片按可见区域加载，加载失败的图片不可选，可单独重试。

用户不必等待全部获取结束即可选择并保存。点击候选只修改弹窗草稿；底部左侧提供停止获取或继续获取，右侧为取消和保存封面。停止取消在途读取，不再开始下一项，保留已返回结果与选择；继续只处理未完成来源，失败来源单独重试。关闭弹窗或离开页面停止读取且丢弃未保存选择。保存失败保留弹窗和选择，支持重试。

保存后详情、书架、最近阅读和书单统一展示用户选择的封面。切换封面不切换阅读书源，不改变章节和进度；换源及刷新详情继续保留用户封面。“使用书源封面”清除用户选择，恢复跟随来源。没有可用候选时保留当前封面，并提示到切换书源页面搜索。

## 目录与阅读

目录页按 edition 显示章节列表，标题、返回、来源选择、操作按钮和筛选固定在顶部，长目录滚动时仍可操作。手机上背景从屏幕顶边覆盖顶部安全区与留白，桌面上从公共导航栏底边开始覆盖，避免章节从标题区上方露出。切换 edition 保留原返回目标，支持手动刷新。

正文页顶部和底部操作栏默认隐藏；点击正文显示，再次点击隐藏，滚动或选字不触发切换。正文聚焦后 Enter 切换，Escape 优先关闭抽屉或翻页区域，否则隐藏操作栏。滚动模式下底部第一行显示上一章、章节字数、下一章；分页模式下显示当前页/总页数和章节字数，页面本身不提供手动滚动。分页正文支持单指左滑下一页、右滑上一页，抬手后一次翻一页，跨章和位置保存沿用点击翻页行为。滑动需满足横向方向、距离或速度门槛；短慢滑、明显纵向滑动、长按后拖动及明显回撤不翻页，也不触发点击操作。长按选字、选区手柄与复制优先，已有选区时不滑动翻页，静止点击仍可结束旧选区并执行原有分区动作。屏幕左右边缘为浏览器手势保留滑动起始空间，边缘普通点击仍可翻页；工具栏、抽屉和翻页区域编辑器不参与正文滑动。分页模式的翻页区域位于顶部更多菜单的书籍详情下面，编辑器预览左、中、右三栏和中栏上、中、下三段；拖动分割线可调整各区比例，上、下栏可分别设为上一页或下一页，中栏点击仍切换操作栏。关闭按钮或 Escape 丢弃草稿，点击预览不关闭，只有“保存设置”成功后才应用；设置随账号同步并包含在设置备份中。第二行依次提供目录、书签、设置和换源；右侧悬浮圆形按钮上方添加或取消当前位置书签，下方切换日夜模式，两者随操作栏显隐。分页正文铺满阅读视口，不为隐藏的顶部和底部操作栏预留空间，保留安全区域、公共顶部留白和阅读设置中的上下左右正文边距；滚动模式也在公共顶部留白之后叠加用户设置的正文上边距。目录抽屉的操作区左侧显示“展开”入口，点击进入完整目录页，右侧提供倒序、到顶部、到底部和刷新目录数据；这些操作在同一行左右分布。刷新成功后更新当前书籍的共享目录缓存，失败时保留现有目录并显示重试入口。完整目录页打开时将已有阅读进度对应章节居中展示；该章节与目录抽屉的当前章节使用一致的浅背景、上下分隔线和较大对号。字数按展示正文的 Unicode 字符计数，排除空白、包含标点，不含标题。日夜快捷键以当前实际模式切换并保存账号偏好，保存失败可重试；设置仍可选择跟随系统。阅读设置从账号设置读取，支持设置正文上、右、下、左四边距。操作栏显隐保持正文布局与滚动位置。首次加载同时读取目录、正文和位置；保留的同章阅读实例恢复时直接显示已有正文，不重新请求正文、位置或重复设置活动来源。切换章节、书籍或书源后按目标身份加载，主动刷新仍获取最新内容。保存位置带 paragraphIndex、offset、tocRevision 和 version，服务端按用户、书籍和 edition 更新。

空目录、空正文、来源能力缺失、网络失败和取消分别显示可识别状态。正文加载失败不会删除已有缓存或阅读位置。

书架和阅读记录直接打开正文；翻章、目录抽屉和换源保留原返回目标，返回时恢复首页对应标签。阅读顶部仅显示章节标题本身，不额外添加数字序号，右侧使用与书架条目一致的更多菜单，提供书籍详情、翻页区域、查看原文、刷新内容。点击其他区域或按 Escape 会自动关闭菜单；刷新失败保留当前正文，成功后尽量恢复可见段落。

底部导航、阅读栏和抽屉避让安全区域，顶部增加间距，标题区优先横排。抽屉点击外侧区域、关闭按钮或按 Escape 关闭。账号设置顶部显示账号，下方依次提供修改密码、书源管理和阅读设置入口，阅读设置进入二级页面，底部的退出登录按钮使用淡红色强调；字号、行距和正文四边距均保留滑块，并提供减小、增大按钮，字号步长为 1，行距步长为 0.1，边距范围为 0～64px，保存成功不显示额外提示，失败仍显示错误。

## 书签与笔记

阅读底栏的书签入口打开当前书籍的双页签抽屉，左书签、右笔记。书签记录可视正文位置，笔记包含只有标记的摘录和附带想法的摘录；按章节与文字位置排列，点击按原来源版本返回正文。原来源不可用时保留摘录并提示；正文变化不能唯一定位时保留笔记且不猜测位置。

选字后显示五色浮窗，顺序为粉、紫、蓝、绿、橙黄，右侧“想法”；选色保存同色下划线与浅背景。未选色直接确认想法默认橙黄。点击已有标记时显示当前色对勾和删除，有想法时展开内容且按钮显示“编辑”，无想法时按钮显示“想法”。删除直接移除标记与想法，设置笔记页的已删除列表可以恢复。清空已有想法保留标记。部分重叠的选区需编辑原标记或重新选择，不自动合并。

设置中的笔记页显示账号全部书籍的笔记，顶部一行左搜索、右书籍筛选；关键词匹配摘录及想法，书籍选项包含活动和已删除笔记的书籍。条目显示书名、创建时间、摘录及可选想法，按创建时间倒序，每次加载50条；编辑不改变顺序。正常列表提供编辑与删除，已删除列表提供恢复；恢复冲突提示处理已有重叠标记。搜索条件保存在URL，返回页面保留状态与滚动。书签不混入该页。

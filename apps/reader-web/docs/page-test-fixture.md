# reader-web 页面验收模拟服务

`tests/fixtures/page-test-server.mjs` 提供独立的本地认证响应和内存 API，用于手工检查页面布局、导航、搜索、目录、正文、书源切换和设置。它不连接 Supabase、PostgreSQL 或真实书源，服务重启后数据会恢复初始状态。

## 启动

在仓库根目录开两个终端。第一个启动模拟 API 和认证服务：

```bash
pnpm --filter @legado/reader-web dev:page-fixture
```

页面验收时用这个服务代替 `dev:api`；它占用相同的 8787 端口。

第二个终端把浏览器端 Supabase 配置指向模拟服务并启动前端：

```bash
PUBLIC_SUPABASE_URL=http://localhost:8787 \
PUBLIC_SUPABASE_PUBLISHABLE_KEY=reader-web-page-fixture-key \
pnpm --filter @legado/reader-web dev
```

打开 `http://localhost:3000/login`，使用以下测试账号：

```text
reader@example.test
fixture-password
```

测试账号只由本地模拟认证端点接受。不要将这组凭证配置到真实 Supabase 项目。

第二账号为 `reader2@example.test`，密码同为 `fixture-password`。它拥有独立空书架、空书源和设置，不可读取第一账号书籍，用于检查退出及账号切换后的页面清理。

## 样例数据

- 书架和阅读记录包含一本《星海旅人》，有两个书源版本和30章目录，每本书只保留一份当前进度，默认停留在第二章。
- 书源管理包含65个启用书源；书源地址使用保留的 `.test` 域名，不对应真实网站。
- 发现按当前书源提供8个分类，每页12条书籍、共3页；02号源返回空列表，03号源的第二页首次失败，04号源提示动态分类不支持，05号源首次打开详情失败。失败状态均可通过页面“重试”恢复，重启服务会重置这些状态。
- 搜索最多逐个返回5个同书名结果，并间隔80毫秒发送 SSE 事件，便于检查结果逐步出现、取消与来源选择。
- 正文包含28段；刷新正文会显示递增的刷新标记。
- 书名、书籍地址和章节地址包含较长文本，可检查窄屏下的省略和操作按钮位置。

模拟 API 支持页面验收所需的登录、首页、书源列表、搜索流、书籍详情、版本、目录、正文、阅读位置、设置、书单和分组接口。搜索、书架、阅读位置、设置和书源管理操作会修改当前进程内的数据；停止服务后这些修改会清空。请求日志只输出方法、路由和 `refresh=true` 或 `all=true` 标记，不记录请求体、认证头或搜索词。

该服务用于页面与交互验收，不替代 Hono API、Supabase、PostgreSQL、书源解析或真实 iPhone Safari 的集成验证。

## 封面切换验收

《星海旅人》的详情封面可以打开切换封面窗口。初始两个已保存来源有可用封面，另有两条封面样例验证重复封面合并和图片加载失败，三个已发现来源依次读取：03号源返回封面，04号源返回来源失败，05号源没有封面；每次读取延迟1500毫秒，便于检查停止和继续。图片由本地 `/api/fixture-cover/` 返回，不访问真实书源。保存和恢复默认只修改模拟书籍的用户封面，保持活动 edition 和阅读位置。

先在获取过程中停止，确认已返回图片保留，再继续获取。选择另一张封面保存，检查详情及书架显示一致；重新打开选择“使用书源封面”，确认恢复。通过失败注入让封面 PUT 首次失败，检查弹窗和选择保留且可重试。另检查320px、390px和桌面下网格、长来源名称及底部操作按钮可达。

## 页面保留验收

仅模拟服务暴露 `GET /__fixture/status`，返回按请求方法和路径统计的 `counts`；不记录查询词、请求体或令牌。`POST /__fixture/control` 接受 JSON：`reset: true` 恢复初始数据、计数和失败状态；`route` 指定如 `GET /api/home`，`delay` 设置 0～10000 毫秒延迟，`failures` 设置接下来 0～10 次失败；同时设置 `unauthorized: true` 可模拟应用登录失效的 401 响应。重置后刷新页面，避免继续使用重置前的内存状态。

先记录计数，再执行“书架切标签 → 发现 → 设置 → 书架”，检查标签保持且 `/api/home` 未增加。搜索完成后进入详情再返回，检查关键词、候选和展开状态保持，未新增搜索。正文打开详情再返回，检查正文 GET 和活动 edition PUT 未增加；完整目录选章或下一章后，返回不逐章回退。

通过延迟注入检查首次读取时离开、搜索运行时离开和保存时离开；通过失败注入检查错误保留与显式重试。再检查前进后退、九个内容页触发淘汰、窄屏浮层关闭、分页模式切换及第二账号无旧数据。逻辑边界另由 `page-stack.test.ts`、`page-resource.test.ts` 和 `reading-position-queue.test.ts` 覆盖。

阅读设置合并保存：记录 `PUT /api/settings` 计数，在 500ms 内连续调整字号或边距，页面应即时预览，停止后只新增一次写入；修改字号后立即切换阅读模式，应合并为一次即时提交。再检查修改后立即关闭阅读抽屉、离开设置页及切到后台时提交剩余值。为 `PUT /api/settings` 注入延迟，继续修改时预览不能被旧响应回退；注入一次失败后保留预览并显示重试，重试成功后错误消失。登出并切换第二账号，不能显示或发送第一账号的未发送修改。定时、慢请求串行、失败字段保留和队列销毁另由 `settings-save-queue.test.ts` 验证。

## 书单与分组验收

模拟服务复用组织数据业务规则，支持书单增删改、独立评价、成员恢复、分组管理、排序和修改归属；组内书籍与现有书架、搜索数据联动。初始没有自定义分组和书单，重置时清空组织数据。第二账号拥有独立组织数据。

先从书单新增，再从书架菜单加入；编辑评价后移除，进入书籍信息再返回应保留移除行与加入按钮。从书单详情进入搜索，加入书单始终打开窗口并预选来源书单。设置页新增两个分组、调整顺序、选择启动组，书架分组栏应同步排序；刷新使用启动组，站内返回保持当前筛选。

## 导入管理验收

模拟服务使用真实 MemoryReaderRepository 保存两个来源批次，每批3条，与65条旧页面样例分开。重启恢复初始状态。检查第二来源置顶、批次明细、选中或整批撤销，以及撤销后历史保留。桌面与390px宽度均检查来源文本、按钮、分页和返回。

规模验证在仓库根目录执行：

```sh
node --max-old-space-size=192 --test apps/reader-web/tests/scale/source-search.test.ts
```

192 MiB 是测试进程的 V8 堆预算，不是整个进程内存；报告另行测量 RSS。测试保留2,000源和40,000候选，使用真实解析及单源 runtime，仅模拟外站响应。设置 `READER_WEB_SCALE_DATABASE_URL` 可验证生产 Repository 的数据库路径，必须指向已执行迁移的独立测试库，该模式会保存模拟账号的数据，禁止使用业务库。

## 书签与笔记验收

正文选字后可选择五色或直接输入想法，点击已有标记显示改色、想法与快速删除。底栏书签打开当前书籍双列表，右侧悬浮书签记录当前位置；设置笔记页可组合关键词与书籍筛选，正常记录删除后在已删除页恢复。第四章提供链接、br换行、嵌套标签和HTML实体正文，用于检查精确范围与点击标记不跳转链接。模拟服务复用批注领域规则，写入、列表、删除和恢复均有状态；reset清空模拟笔记。数据库RLS、版本及备份语义由reading-marks测试验证，模拟服务不替代真实后端验收。


## 统一正文浏览器回归

在仓库根目录先构建 source-core 和 source-node，然后在 `apps/reader-web` 运行 `./node_modules/.bin/rsbuild dev --config tests/fixtures/reading-content.config.ts`，打开 `http://127.0.0.1:3001/`。这是独立测试入口，不加载账号、数据库或生产页面；页面显示 PASS 及断言数量，失败显示实际值与预期值。

该入口使用真实浏览器 DOMParser、React 正文和 DOM Range，验证 core 夹具预期、浏览器与 Node 的完整模型一致、跨段 UTF-16 选区、笔记高亮及工具栏更新后的文本节点稳定性。它不替代手机系统长按验收；完整阅读交互仍使用上面的内存模拟服务。

## 书架刷新验收

从书架条目菜单的“查看目录”下方点击“刷新章节”，首次为当前版本追加3章，之后刷新不再追加。默认第2章阅读位置对应的未读数从28增加到31，最新章节从第30章变为第33章，并出现“更新”。对照 `/__fixture/status` 确认刷新没有新增 `GET /api/home`；重载浏览器后标签仍在，进入阅读页再返回后消失。reset 会清空追加章节状态。

为该书的 `POST /api/books/:bookId/toc/refresh` 注入延迟或失败，检查按钮禁用、书名后加载图标及失败后原数据保留；成功重试后更新摘要。窄屏验收使用320px和390px，检查三行信息在封面旁居中，作者与最新章节同排，未读数位于阅读进度前，长书名及最新章节省略，更新标签保留。
